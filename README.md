# 100 best new remote jobs this week, by country

Every Monday, the 100 best new remote jobs open to people in each of 21 countries: English-language jobs that say, in the post's own words, that they hire where you live. Picked by [First Monday](https://firstmonday.ai/?utm_source=github&utm_medium=repo&utm_campaign=readme), from employers' own job boards.

The first lists arrive on the first Monday after launch, at about 06:00 UTC.
